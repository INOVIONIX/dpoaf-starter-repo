## 🚀 60-second start

1. Click the green **"Use this template"** button (top right) → **"Create a new repository"**
2. Pick a name, set visibility, click **"Create repository from template"**
3. Open your new repo → click **"Issues"** → **"New issue"** → you'll see 3 D-POAF templates ready to fill

That's it. Your repo now has governance for AI-enabled software delivery built in.

## 🧰 What's installed

| File | What it does |
|---|---|
| `.github/ISSUE_TEMPLATE/wave-scope.yml` | 🌊 Open a new Wave (governed unit of AI work) |
| `.github/ISSUE_TEMPLATE/prompt-action.yml` | 🤖 Log every AI generation event (model + config + context) |
| `.github/ISSUE_TEMPLATE/proof-record.yml` | ✅ Close a Wave with PoD / PoV / PoR evidence |
| `.github/PULL_REQUEST_TEMPLATE.md` | 🛡 Enforces Dynamic Laws DL-001, DL-002, DL-005, DL-006, DL-011 |
